## 3. 新人快速开始

### Step 1：了解背景
1. 先读本 `README.md`
2. 再读 `docs/onboarding.md`
3. 再读 `CONTRIBUTING.md`

### Step 2：准备开发环境
- 安装 Git
- 配置 SSH key（如需）
- 克隆仓库并切换到个人分支

### Step 3：完成第一次提交
1. 新建分支：`feat/<your-topic>`
2. 改动一个小文档或小脚本
3. 通过本地检查（见下方）
4. 提交并发起 PR

## 4. 本地检查（基础）
当前仓库暂无语言构建系统，建议至少执行：

```bash
git status
```

后续接入代码后，补充：
- lint
- unit test
- integration test

## 5. 协作约定（摘要）
- 小步提交，提交信息语义化
- PR 要有背景、方案、验证结果
- 所有设计与决策要落文档，避免知识只在口头
