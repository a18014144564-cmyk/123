# 新人入门建议（30 天）

## 第 1 周：建立全局认知
- 明确项目目标、边界和核心术语
- 熟悉仓库结构与开发流程
- 完成一次最小 PR（建议先文档改动）

## 第 2 周：理解关键链路
- 跟踪一条核心业务流（输入 -> 处理 -> 输出）
- 梳理上下游依赖（数据库、消息、外部服务）
- 记录问题并补充 FAQ

## 第 3-4 周：独立交付
- 认领一个小功能或缺陷
- 完成：方案 -> 开发 -> 测试 -> PR -> 合并
- 输出一页复盘：风险、收益、改进点

## 常见高频问题（模板）
1. 这个仓库的职责边界是什么？
2. 出问题先看哪里（日志/监控/告警）？
3. 哪些改动风险最高，需要提前评审？
